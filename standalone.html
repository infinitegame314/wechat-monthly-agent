HOW IT WORKS

它不是再写一篇摘要，
而是在做信息收口。

01

只收已完成周报

先确认覆盖期、产物和完成状态。运行中或缺证据的周报，不混进月报。

02

跨周合并与追踪

同一线索只保留一个主条目，同时记录它从首次出现到最新状态的变化。

03

分成阅读与行动

观点和不确定信息进入“需精读”；下一步可验证的事项才进入“待执行”。

04

保留来源与缺口

每项都能回到对应周次。缺失、冲突和统计口径会原样标出。

OUTPUT STANDARD

好月报的标准，
不是“内容很多”。

01读什么，有理由影响判断、跨周重复、存在分歧或具有明确时效。
02做什么，能落地动作对象和最小下一步明确，不把观点硬改成任务。
03不知道，就写不知道不补负责人、截止时间、数字和未核验的完成状态。
CAPABILITY BOUNDARY

看得到能力，
碰不到你的权限。

公开网页和本地 Agent 完全分离。这个页面只负责解释与演示；真实汇总只在你授权的本地环境发生。

01

不连接

微信、飞书、联系人或任何私有 API

02

04
